# 证据可采性评估框架

## 四级过滤流程

```
证据是否与待证事实相关？
  ├── 是 → 继续
  └── 否 → 排除
         ▼
证据是否合法取得？
  ├── 是 → 继续
  └── 否 → 评估是否可补救 / 排除
         ▼
证据是否可靠/真实？
  ├── 是 → 继续
  └── 否 → 寻找佐证 / 降低权重
         ▼
证据是否最优证据？
  ├── 是 → 可采纳
  └── 否 → 是否满足例外条件？→ 可采纳但说明理由
```

## 证据充分性判断（SPIRIT 框架）
- **S**ufficient — 数量是否足以排除合理怀疑？
- **P**ertinent — 是否直接相关于待证事实？
- **I**ndependent — 是否有独立来源相互印证？
- **R**eliable — 来源和保管过程是否可靠？
- **I**ntegrity — 完整性是否受到保护？
- **T**imeliness — 是否及时收集？
