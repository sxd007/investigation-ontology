# 判断与置信度更新

本参考说明如何在不制造伪精确的前提下更新调查判断。

## 三种不同对象

不得把三种 `confidence` 混为一谈：

| 对象 | 数据表示 | 用途 |
|---|---|---|
| HYP 假设 | `0..1` 数值，可选 | 表示当前分析权重，Schema 以 `hypotheses[].confidence` 为准 |
| EV 证据 | `suspected / probable / confirmed` | 表示证据条目的核实程度，Schema 为准 |
| FND 发现 | `suspected / probable / confirmed` | 表示事实认定的充分程度，Schema 为准 |

`not_applicable` 是适用性或处置状态，不是置信度。`likely` 不用于 EV/FND 的结构化字段。

## 贝叶斯纪律

贝叶斯公式表达的是更新纪律：

$$P(H\mid E)=\frac{P(E\mid H)P(H)}{P(E)}$$

实际调查中，只有在存在可靠基准率、可解释的似然估计和足够独立的数据时，才适合进行数值计算。否则，AI 不得凭语感生成看似精确的概率。

无法可靠量化时，使用方向性更新：

- 显著上升；
- 轻微上升；
- 基本不变；
- 轻微下降；
- 显著下降。

每次更新必须记录触发证据、支持与反对理由、剩余疑点，以及是否需要调查员确认。

## HYP 数值的使用边界

需要写入 HYP 数值时：

1. 数值是可修订的分析值，不是客观统计概率；
2. 说明初始值的依据；
3. 说明本次变化由哪些证据触发；
4. 不得仅因缺乏反证而上调；
5. 不得把同源材料拆成多个证据后重复加权；
6. 数值变化不能自动决定法律、纪律或结案结论。

没有合理依据时可以暂不填写可选 `confidence`，但仍应记录状态、证据方向和不确定性。

## 证据依赖与重复计算

更新前检查：

- 多份材料是否来自同一原始来源；
- 后一份材料是否只是引用前一份材料；
- 多名证人是否互相沟通后形成一致陈述；
- 系统报表是否来自同一底层数据；
- 分析结果是否只是对同一原始证据的不同变换。

同源一致不能被当作独立印证。真正的独立印证应来自相互独立的生成过程。

## 更新记录模板

- 假设：`HYP-NNN`
- 原判断：数值或方向
- 新证据：`EV-NNN`
- 支持作用：为什么支持
- 反驳作用：为什么反驳或限制
- 独立性：独立 / 同源 / 不确定
- 更新建议：方向或数值
- 剩余疑点：尚未解决什么
- 人工确认：需要 / 不需要

假设转为 `confirmed` 或 `rejected`、发生重大判断变化、扩大调查范围或形成正式 finding 时，必须由调查员确认。
