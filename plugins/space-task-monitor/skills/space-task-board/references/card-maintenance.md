# 卡片维护：建卡 / 改卡 / 提升为项目

## new —— 建卡

1. **先判断是项目还是任务**：子项会 >=3 个吗？跨多个会话吗？→ 项目；否则任务。
   **再判断 std 还是 mini**：一个动作一句话说清、完成与否无争议、单会话可完成、无蔓延空间，
   四条全中 → `granularity: mini`（只必填「目标」）；任一不中 → std（必填三项）
2. 读对应模板（`<技能目录>/templates/`）
3. 分配 ID：扫 `tasks/`，`P-` 取最大 +1，`T-` 取最大 +1。**ID 不回收** —— done/dropped 占掉的号不补
4. **落盘前必须与用户确认三项**（任务卡）：**目标**（须可验收，写成"能做什么"）· **范围（不做什么）** · **验收标准**。
   项目卡再加：**验收标准须可测**（如"3 分钟内找到 X"）
   **不要自行编造目标与范围** —— 用户没说就问
5. **如实标 `def_source`**：三项经用户明确表述/确认 → `user` + `def_confirmed: 当天`；
   AI 从材料抽取未确认 → `extracted`；AI 归纳推断未确认 → `inferred`。
   **推断不丢人，冒充确认才丢人** —— 看板会把非 user 的卡标「定义待确认」
6. 文件名 `P-<n>-<slug>.md` / `T-<n>-<slug>.md`
7. 落卡后同步 `TASKS.md` 看板，刷新「最后更新」

## update —— 改卡

1. 定位卡片（按 ID 或标题关键词）
2. 更新对应段落 + frontmatter `updated`
3. `TASKS.md` 与 board.html 是派生物，**不手改** —— 下次 refresh 自动重生成；急看就跑 `refresh_board.py --write-tasks-md`
4. 子项 `done` → 项目卡子项完成比 +1，「近期完成」记一行；看板子项表**可保留该行并标 `done`**（近 30 天），满 30 天清理
5. 项目全部子项 `done` → 项目 `status: done`，移入看板「近期完成」
6. `dropped` → 卡内写一行放弃原因，同样移出
7. 看板网页（board.html）**不需要**手动刷 —— 下次定时刷新自动更新；用户急看就重跑晨间刷新任务

## promote —— 提升为项目

**触发**：某独立任务的子任务涨到 >=3 个，或开始跨会话。

1. 建 `P-<n>-<slug>.md`，把原卡的目标/范围上移（补充项目级验收标准）
2. 原卡加 `project: P-<n>`，成为子项
3. 新子任务建卡并填 `project:`
4. `TASKS.md` 改为按项目分组
5. **不为提升而提升** —— 只有真跨多会话、多子项时才做

## 字段语义（模板字段统一口径）

- `priority`：P0 最高（不通则关键路径断裂）＞ P1 ＞ P2 ＞ P3（可缓）。项目与任务同口径
- `next_review`：**预留字段，不强填**；若用，按 `YYYY-MM-DD` 写下次复核日。看板网页对超期卡被动标红，不主动提醒
- `granularity`：`std`（默认，必填三项）/ `mini`（只必填「目标」；判据与升级护栏见模板注释）
- `due`：真·截止日（`YYYY-MM-DD`，可空）；与 `next_review`（复核节奏）是两回事，看板对临期/逾期提示
- `blocker`：阻塞归因 `user` / `external` / `internal`（仅 waiting/blocked 时填；不填则看板按文本推断，不如填了准）
- `def_source`：`user`（用户表述/已确认）/ `extracted`（AI 材料抽取待确认）/ `inferred`（AI 归纳推断待确认）
- `def_confirmed`：用户确认定义的日期（`YYYY-MM-DD`）；确认后 `def_source` 改 `user`
- **定义待确认** = 非 `user` 且无 `def_confirmed`，或必填项有留空 —— 看板自动标灰徽章并在总览提示
- `sessions`：由下班收尾流程回填（哪些会话推进了本卡），弹窗显示计数
- `children`：统一带引号写法 `["T-001", "T-002"]`（解析脚本按此剥离）
- `kb_refs`：只写路径，不复制内容
- `sessions`：由下班收尾流程回填（哪些会话推进了本卡）

## 完成定义核对（改卡为 done 前）

- 验收标准逐条过：真满足了吗？还是"差不多"？
- 产物路径写进「已完成」了吗？（卡是索引，指向要具体）
