# 调查技术参考

调查中可用的技术手段参考 — 不同场景选不同的手段，本技能提供方法论指导和选型建议。

> **定位：** 本技能是 investigation-foundation 在操作层面的展开——foundation 讲"调查时该怎么想"，本技能讲"有哪些调查手段、怎么选、注意什么"。多数技术需要调查员人工执行，本技能提供流程指导和注意事项；AI 可辅助的环节（如基础 OSINT 检索、文本分析）会主动执行。

## 配置前置检查

在执行本技能的业务操作前，按以下流程检查用户配置：

```
检查 {配置路径}/team-profile.md
├── 不存在 / 含 [PLACEHOLDER] / 含 PAUSED 标记
│   └── 自动进入 /efio:cold-start 配置向导，完成后继续
└── 配置就绪 → 继续
```

详细规则参见 `config-templates/config-loader.md`。

此技能当前无需读取特定配置项，仅检查配置就绪状态。

## When to Activate

- 为调查方案选择具体调查手段时
- 需要了解数字取证、OSINT、通讯分析等技术的流程和注意事项时
- 评估调查资源需求（需要什么技术/工具/外部资源）时
- 指导调查员执行 AI 无法代劳的技术（硬盘取证、实地勘查等）时

## 关键技术详述

### 数字取证流程

```
识别 → 保全 → 采集 → 分析 → 报告
```
- **识别：** 确定可能的证据源（设备/系统/云）
- **保全：** 写保护接入 → 计算哈希 → 镜像复制
- **采集：** 按照优先级收集（易失性数据优先：内存→网络连接→磁盘）
- **分析：** 文件系统分析 → 关键词搜索 → 时间线重构 → 关联分析
- **报告：** 取证过程记录 → 发现汇总 → 结论 → 保管链完整性声明

> 数字取证需要专业工具（写保护器/取证镜像设备/FTK/EnCase 等）和物理接触，AI 无法代劳。本节供调查员参考执行流程和注意事项。

### OSINT 调查框架

| 层面 | 来源 | 关注点 |
|------|------|--------|
| 个人层面 | 社交媒体/论坛/博客 | 职业轨迹/生活方式/异常关联 |
| 公司层面 | 工商注册/年报/招聘 | 股权结构/经营状况/人员变动 |
| 技术层面 | WHOIS/DNS/SSL证书 | 域名归属/IP溯源/基础设施 |
| 关系层面 | 社媒关系/合作网络 | 未披露的关联/利益冲突 |
| 深网层面 | 法院记录/公共数据库 | 涉诉记录/行政处罚/失信信息 |

> 基础 OSINT 检索（搜索引擎查询、公开网页阅读）AI 可辅助执行。深度 OSINT（专业数据库、社交媒体深度挖掘）需要调查员手动操作。

### 通讯分析

- **通话记录分析** — 频率模式/异常时段/联系人聚类
- **通讯模式识别** — 某事件前后的通讯激增或静默
- **联系人网络构建** — 从通讯记录提取关系图谱
- **邮件元数据分析** — 发送时间/IP地址/邮件客户端指纹

> 如有结构化的通讯数据（CSV/Excel），AI 可辅助分析模式和异常。获取通讯记录本身需要合法程序和人工操作。

### 实地调查

- **现场勘查** — 物证位置记录/拍照取证/环境观察
- **物证采集** — 遵循保管链要求/标记封存/移交记录
- **走访核实** — 终端客户/供应商/邻居/前员工
- **隐蔽观察** — 人员活动/车辆/营业状况

> 实地调查完全依赖调查员执行。本技能提供流程和注意事项参考。

### 资产追踪

- **金融资产** — 银行账户/证券账户/保险/理财
- **不动产** — 房产/土地/在建工程
- **动产** — 车辆/设备/存货
- **无形资产** — 股权/知识产权/债权
- **跨境资产** — 境外账户/离岸公司/信托结构

> 资产追踪高度依赖合法的信息获取渠道（法院调查令/协查函等）。AI 可辅助分析已获取的资产数据，但获取过程需要调查员执行。

## 技术选型决策树

```
调查需要什么类型的信息？
├── 财务/交易数据 → data-analysis 技能 (../data-analysis/SKILL.md)
├── 数字证据 → 数字取证 (需专业工具和人员)
├── 公开信息 → OSINT (AI 可辅助基础检索)
├── 社交关系 → OSINT + 关系图谱分析
├── 通讯记录 → 通讯分析 (有数据时 AI 可辅助)
├── 现场信息 → 实地调查 (调查员执行)
├── 资产状况 → 资产追踪 (需合法渠道获取)
├── 当事人陈述 → interview-analysis 技能 (../interview-analysis/SKILL.md)
└── 综合管理 → case-management (../case-management/SKILL.md) + evidence-management (../evidence-management/SKILL.md)
```

## 分析辅助工具

以下工具类型可辅助加速调查操作。**这些工具不是必须的**——未配置时，由模型按调查标准直接完成。

如环境中配置了以下类型的 MCP 服务器，可辅助加速：
- **网络搜索类 MCP**：可用于 OSINT 公开信息检索、背景调查。不可用时由调查员手动浏览器搜索
- **深度搜索类 MCP**：可用于更深入的互联网数据挖掘（通常需要 API Key）。不可用时跳过
- **邮件分析类 MCP**：可用于解析邮件头、分析元数据。不可用时手动分析
- **图表生成类 MCP**：可用于生成调查发现的可视化展示。不可用时用文本表格描述

> 注意：多数调查技术（数字取证、实地调查、资产追踪）没有对应的 MCP，需要调查员使用专业工具执行。AI 的角色是提供方法论指导和选型建议。
